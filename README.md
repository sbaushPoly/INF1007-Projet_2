# INF1007-Projet_2

## Description du projet:
- Prédit la note finale d'examen à partir des caractéristiques et habitudes données par l'utilisateur
- Selon l'objectif de note choisi par l'utilisateur et la position des caractéristiques selon la moyenne pour cette note, propose des changements aux habitudes

## Source
L'ensemble de données utilisée pour ce projet est la suivante:
[Digital Distraction vs Academic Performance](https://www.kaggle.com/datasets/neurocipher/digital-distraction-vs-academic-performance)
Par NeuroCipher sur Kaggle
